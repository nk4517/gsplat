# Hybrid Sky Rendering Approach

## Overview
Гибридный подход для рендеринга, комбинирующий:
- **Единую сферическую модель неба** (skysphere) - общая для всех камер, рендерит только небо
- **Индивидуальные 2D сплаты** - уникальные для каждой камеры, рендерят мир/передний план/артефакты

## Мотивация
Сферическая модель неба обеспечивает консистентное небо между видами. 2D сплаты нужны для рендеринга переднего плана (мир, объекты) и локальных артефактов (блики, отражения), которые могут перекрывать небо в конкретных видах.
## Архитектура

### 1. Skysphere Model (SkysphereModelParametrized)
- Использует кватернионную параметризацию для позиций на сфере
- Рендерится через WEIGHTED_SUM режим в gsplat
- Общие параметры для всех камер:
  - `quats` - кватернионы (определяют позицию и ориентацию)
  - `scales` - масштабы сплатов
  - `colors` - RGB цвета


### 2. SH Background (SHBackgroundModel)
- Глобальная модель фона на основе сферических гармоник
- Заполняет области с низким покрытием skysphere (низкий wsum)
- Параметры:
  - `sh_coeffs` - обучаемые коэффициенты SH [K, 3], где K = (degree+1)²
  - `sh_degree` - степень SH (обычно 2-4)
  - `bg_base_weight` - базовый вес для блендинга
  - `bg_threshold` - порог wsum, выше которого SH background не виден

#### Блендинг неба
```
bg_weight = bg_base_weight * clamp((bg_threshold - sky_wsum) / transition_range, 0, inf)
final_colors = (sky_colors + sh_bg * bg_weight) / (sky_wsum + bg_weight + eps)
```
- Плавный переход между skysphere и SH background
- В областях с высоким wsum доминирует skysphere
- В областях с низким wsum проявляется SH background

#### Рендеринг SH Background
- Вычисляетcя направление луча для каждого пикселя
- Направление преобразуется из camera space в world space
- Рассчитываются RGB цвета для этого направления
- Результат клампируется в диапазон [0, 1]

### 3. Per-Camera 2D Splats (Gaussian2D from LIG)
- Индивидуальные 2D гауссианы для каждой камеры
- Рендерят передний план (мир, объекты) и артефакты
- Параметры хранятся в embedding:
  - `means` - позиции 2D гауссиан (xy)
  - `cov2d` - параметры ковариации
  - `rgbs` - цвета
  - `uncertainty` - маска блендинга (active uncertainty)

### 4. Blending (в процессе)
```
final_render = r_2d + (1 - uncertainty_mask) * r_sphere
```
где:
- `r_sphere` - рендер сферического неба (фон)
- `r_2d` - рендер 2D сплатов для текущей камеры (передний план + артефакты)
- `uncertainty_mask` - обучаемая маска, определяющая где есть передний план/артефакты

## Преимущества
1. **Консистентность** - сферическая модель обеспечивает согласованное небо между видами
2. **Детализация** - 2D сплаты точно рендерят передний план и локальные артефакты
3. **Эффективность** - 2D сплаты рендерятся только для активной камеры
4. **Адаптивность** - маска uncertainty автоматически учится разделять небо и передний план

## Оптимизация
- Сферическая модель и 2D сплаты оптимизируются совместно
- Маска uncertainty обучается определять, где нужны локальные корректировки
- Используются отдельные оптимизаторы с разными learning rate для разных компонент
